# SlidevLink Component

`SlidevLink` lets you embed a compact, scaled-down preview of a Slidev presentation inside any MDX documentation page. Clicking the card opens the full presentation.

## Swizzle

`SlidevLink` is **not importable directly**. Use it inside MDX pages by swizzling it first, or reference it via the theme alias that Docusaurus resolves automatically:

```mdx title="docs/my-page.mdx"
import SlidevLink from "@theme/SlidevLink";

<SlidevLink link="/training/getting-started/introduction" />
```

Because `SlidevLink` is a theme component, Docusaurus makes it available under `@theme/SlidevLink` without a manual import path.

To customize it:

```bash
npx docusaurus swizzle slidesaurus SlidevLink --wrap
```

## Props

| Prop       | Type     | Required | Default     | Description                                                                                                                                                                                                                            |
| ---------- | -------- | -------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `link`     | `string` | Yes      | —           | Route of a registered presentation **without the site `baseUrl`** (e.g. `/training/getting-started/introduction`); the `baseUrl` is added automatically. Must match the presentation URL (trailing slash and letter case are ignored). |
| `width`    | `string` | No       | `"550px"`   | CSS width of the card component.                                                                                                                                                                                                       |
| `pluginId` | `string` | No       | `"default"` | Plugin instance ID. Set this when using multiple `slidesaurus` instances in `docusaurus.config.ts`.                                                                                                                                    |

## How `link` resolution works

The component calls `usePluginData()` to retrieve all presentations registered by the plugin. It prefixes `link` with the site `baseUrl`, normalizes it (strips trailing slash, lowercases) and finds the presentation whose `url` matches. If no match is found, the component renders an error card.

```tsx
// This link must correspond to a real presentation URL
<SlidevLink link="/training/getting-started/introduction" />
```

If the presentation is not found, check that the `link` value matches the route generated by the plugin (visible in the browser address bar or in the overview page).

## Multi-instance example

```tsx
// Embed a presentation from the "training" plugin instance
<SlidevLink link="/training/getting-started/introduction" pluginId="training" />
```

## Preview behavior

The card renders a scaled, lazy-loaded iframe pointing to `presentation.previewUrl`, with a spinner while it loads (in both dev mode and production, since both serve the built output). If the presentation has no preview URL, a placeholder icon is shown. The iframe uses the shared `SLIDEV_IFRAME_SANDBOX` policy (see [Presentation Page](./presentation-page.md)).

The card is a `<div>` whose title link is stretched over the card, so the iframe is never nested in an anchor.

The iframe is scaled via a `ResizeObserver`-driven CSS variable so the preview stays proportional at any card width.

## SlidevCard vs SlidevLink

| Component    | Use Case                                                                    |
| ------------ | --------------------------------------------------------------------------- |
| `SlidevLink` | Inline embed inside a documentation page — compact card with iframe preview |
| `SlidevCard` | Grid/list card on the overview page — rich metadata, thumbnail preview      |

Use `SlidevLink` when cross-referencing a presentation from a doc page. `SlidevCard` is used internally by the overview page and is not intended for manual embedding.
